# ありがとう日記

毎日3つ以上の「ありがとう」を残すための小さな日記ツールです。

## できること

- 今日のありがとうを最低3つ記録
- 日付ごとの履歴表示
- 連続日数、今月の達成数、記録日数、合計数の表示
- ブラウザ内への保存
- JSONでの書き出し、読み込み
- Google Apps Script経由でスプレッドシートへ送信
- スマートフォンのホーム画面追加に対応

## 使い方

`index.html` をブラウザで開くと使えます。

スマートフォンから使う場合は、GitHub PagesなどHTTPSで公開できる場所にアップロードしてください。

## スプレッドシート連携

`google-apps-script.gs` をGoogleスプレッドシートのApps Scriptに貼り付け、ウェブアプリとしてデプロイします。

発行されたWebアプリURLを、日記ツールの「シート連携」に貼って保存すると、日記保存時にスプレッドシートへ送信されます。

詳しい手順は `spreadsheet-setup.md` を見てください。
